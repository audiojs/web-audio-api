Web Audio APIheadless

The browser audio graph, implemented in pure JavaScript for Node, CI, servers, Deno, and Bun.

npm install web-audio-api

import { AudioContext } from 'web-audio-api'

const ctx = new AudioContext()
await ctx.resume()

const osc = ctx.createOscillator()
osc.connect(ctx.destination)
osc.start()

Questions

Is it fast enough for realtime?

For simple graphs, yes. The included benchmarks render every measured scenario faster than realtime. Pure JavaScript is competitive on small graphs; convolution and compression are roughly 2–4× slower than the native Rust binding in the repository benchmark. AudioWorklet execution is currently synchronous, so production low-latency work remains the boundary.

How does audio I/O work?

audio-speaker provides the default output device. Microphone examples use the optional audio-mic adapter, then feed PCM into a MediaStreamTrack. You can also set sinkId to any Node writable stream.

Which formats can it decode?

decodeAudioData() uses @audio/decode. It detects and lazily loads codecs for MP3, WAV, Ogg Vorbis, Opus, FLAC, AAC, ALAC, AIFF, CAF, QOA, WebM, WMA, AC-3, DTS, tracker modules, DSD, and more. It can also extract supported audio tracks from MP4, MOV, MKV, WebM, and AVI without FFmpeg or native bindings. Codec packages carry their own licences, so check the decoder’s licence table before distributing a bundled codec.

Does Tone.js work?

Usually. Load web-audio-api/polyfill before importing a browser-oriented library so constructors and window checks exist. Tone.js works with that import order; unsupported DOM APIs still need their own adapter.

Can I test audio in CI?

Yes. Use OfflineAudioContext to render an AudioBuffer in memory, then assert duration, channel count, peaks, RMS, spectra, or exact samples. No speaker, display, or audio device is required.

Can it run without speakers?

Yes. OfflineAudioContext never opens an output device. A realtime AudioContext can also write PCM to a stream instead of the system speaker.

Does it support AudioWorklets?

Yes. Modules can be registered by URL, data URL, Blob URL, or an inline callback in Node. Processors and parameters follow the Web Audio shape. Worklets currently execute synchronously rather than on an isolated realtime thread.

What differs from a browser?

The graph API, 128-frame render quantum, automation model, and node behavior follow the same specification. The boundaries differ: Node needs adapters for speakers, microphones, files, and streams; browser examples on this page use the browser’s native engine.
