Microphone recorder

Capture microphone audio with a live level meter and save a recording.

Browser demonative AudioContext
ready

Sound starts only after you run the demo.

Graph

Microphone → Gain → recorder → file

Input
Microphone stream
Output
Recorded audio file
Runtime
Browser preview · Node CLI
Command
node examples/recorder.js take1 gain=2

CLI options

filename
suggested output name
gain=<number>
input gain
rate=<hz>
sample rate (default: 44100)
ch=<number>
input channels (default: 1)
bit=<number>
PCM bit depth (default: 16)
backend=<name>
audio-mic backend: miniaudio/auto or process
