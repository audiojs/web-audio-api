Programmable metronome

Schedule a click pattern with accents, rests, tempo control, and instrument presets.

Browser demonative AudioContext
ready

Sound starts only after you run the demo.

Graph

Scheduled transients → Master Gain → Destination

Input
Tempo · pattern · sound
Output
Timed clicks
Runtime
Browser preview · Node CLI
Command
node examples/metronome.js 120 X-x-X-x-

CLI options

bpm=<bpm|start..end>
fixed tempo or a linear tempo ramp
-d, --duration <time>
run time (CLI accepts s/m/h suffixes; default: 600s)
pat=<pattern>
X accent, x hit, - or . rest
sound=<preset>
classic, wood, bell, beep, or signal
hi=<hz>
classic stick accent resonance
lo=<hz>
classic stick regular resonance
