Metronome

Schedule a click pattern with accents, rests, tempo control, and instrument presets.

ready

npx web-audio-api metronome 120 X-x-X-x-
bpm=<bpm|start..end>
fixed tempo or a linear tempo ramp
-d, --duration <time>
run time (CLI accepts s/m/h suffixes; default: 600s)
pat=<pattern>
X accent, x hit, - or . rest
sound=<preset>
classic, wood, bell, beep, signal, or karatala
hi=<hz>
classic stick accent resonance
lo=<hz>
classic stick regular resonance
sample=<file>
audio file to use as the click sound instead of a preset

This doubles as an online metronome with sound: set the bpm, an accent pattern like X-x-X-x-, and an instrument voice, then let it click through a practice session. Run it in the browser for a quick bpm click track, or launch the same instrument from the Node CLI to drive a rehearsal, a test, or a batch render.
