CLI options

carrier=<hz|note>
frequency or note name in the CLI (default: 440)
ratio=<number>
modulator/carrier frequency ratio
index=<number>
modulation index
-d, --duration <time>
run time (CLI accepts s/m/h suffixes; default: 30s)
